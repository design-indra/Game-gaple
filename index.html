⚙️ Konfigurasi Firebase

Untuk bermain online, kamu butuh Firebase gratis.

Cara cepat:
1. Buka console.firebase.google.com
2. Buat project baru → Add app → Web
3. Copy konfigurasi, paste di bawah
4. Di Firebase Console: pilih Realtime Database → buat DB → set rules ke true
atau
💡 Tips: Simpan file HTML ini setelah diisi config, agar tidak perlu memasukkan ulang.
